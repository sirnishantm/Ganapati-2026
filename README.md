## Repository Contents

```text
Ganapati 2.0/
├── index.html               # Main SPA shell & Home page
├── explore.html             # Explore standalone entry / fallback
├── map.html                 # Map standalone entry / fallback
├── routes.html              # Curated routes entry / fallback
├── parking.html             # Parking & traffic entry / fallback
├── guides.html              # Guides entry / fallback
├── about.html               # About & licenses entry / fallback
├── css/
│   ├── styles.css           # Core theme variables, typography, rangoli mask, utilities
│   ├── components.css       # Cards, bottom-nav, rails, badges, modals, crowd tracker
│   └── map.css              # Leaflet custom theme, pins, bottom sheets, map filters
└── js/
    ├── data.js              # Comprehensive dataset (29 mandals, 6 routes, 23 parking, 13 closures, guides)
    ├── router.js            # Client-side routing engine (URL path + query params + hash fallback)
    ├── store.js             # LocalStorage state management (Saved bookmarks, Active Plan, Queue Reports)
    ├── map-controller.js    # Leaflet map manager (custom dark tiles, markers, layers, popups)
    └── app.js               # View renderers, search & filter logic, route builder wizard, event listeners

```

## Local Usage

Clone the repository and open the website files in a browser, or deploy the static folder to Vercel.
